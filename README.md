# AllDevTools

AllDevTools is a comprehensive, privacy-focused web application that provides developers with essential tools for coding, data manipulation, and productivity. Built with React and designed to run entirely in the browser, ensuring your data never leaves your device.

## 🚀 Features

### Code & Data Conversion Tools
- **JSON Formatter & Validator** - Format, validate, and beautify JSON data
- **CSV ↔ JSON Converter** - Convert between CSV and JSON formats
- **XML ↔ JSON Converter** - Transform XML documents to JSON and vice versa
- **YAML ↔ JSON Converter** - Convert YAML configuration files to JSON
- **SVG to Code Converter** - Convert SVG graphics to various code formats
- **HTML ↔ Markdown Converter** - Transform between HTML and Markdown

### File Conversion Tools
- **PDF ↔ Word Converter** - Convert between PDF and Word documents
- **PDF ↔ DOC Converter** - Handle legacy DOC format conversions
- **Image ↔ PDF Converter** - Convert images to PDF and extract images from PDFs
- **JPG ↔ PDF Converter** - Specialized image to PDF conversions

### Code Formatting & Validation
- **JSON Formatter** - Advanced JSON formatting with validation
- **SQL Formatter** - Format and beautify SQL queries
- **HTML Formatter** - Clean up and format HTML code
- **CSS Formatter** - Organize and format CSS stylesheets
- **JavaScript Formatter** - Format and validate JavaScript code
- **Regex Tester** - Test and debug regular expressions

### Data Generation Tools
- **UUID Generator** - Generate RFC 4122 compliant UUIDs
- **Password Generator** - Create secure, customizable passwords
- **Lorem Ipsum Generator** - Generate placeholder text
- **Color Generator** - Generate color palettes and codes
- **Slug Generator** - Create URL-friendly slugs
- **JWT Decoder** - Decode and inspect JSON Web Tokens

### Developer Wellness Tools
- **Devodoro Timer** - Pomodoro technique adapted for developers
- **Stretch Breaks** - Guided stretching exercises for long coding sessions
- **Breathing Reset** - Breathing exercises to reduce stress and improve focus

## 🔒 Privacy & Security

- **Zero Data Collection** - All processing happens locally in your browser
- **No External APIs** - No data is sent to external servers
- **Client-Side Only** - Your files and data never leave your device
- **Open Source** - Transparent codebase you can inspect and contribute to

## 🛠️ Technology Stack

- **Frontend**: React 18 with modern hooks and functional components
- **Styling**: Custom CSS with CSS variables for theming
- **Icons**: Feather Icons for consistent iconography
- **Libraries**:
  - UUID generation with `uuid` library
  - PDF processing with PDF.js
  - Syntax highlighting with Prism.js
  - File handling with browser File API

## 🚀 Getting Started

### Prerequisites
- Node.js 16+ and npm
- Modern web browser with ES6+ support

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/alldevtools.git
cd alldevtools
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Build for Production

```bash
npm run build
```

This creates an optimized production build in the `build` folder.

## 📖 Usage

### For Developers
AllDevTools is designed to be intuitive and requires no setup. Simply:

1. Navigate to any tool from the homepage
2. Input your data or configure options
3. Get instant results

### Tool Categories

#### Converters
Use conversion tools to transform data between different formats. These tools handle complex nested structures and preserve data integrity.

#### Formatters
Code formatters help maintain clean, readable code. They include syntax validation and customizable formatting options.

#### Generators
Generate test data, unique identifiers, and other development resources. Perfect for prototyping and testing.

#### File Converters
Process documents and images directly in your browser. Convert between PDF, Word, and image formats without uploading files.

#### Wellness Tools
Maintain your health and productivity with developer-specific wellness features including timers and exercise guides.
